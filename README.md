# Task Management Dashboard

A responsive task management dashboard built with React.js and Vite.

## Features

- Create, edit, and delete tasks
- Task title, description, priority, and status
- Search tasks by title
- Filter by task status
- Sort by creation date and priority
- Task statistics
- localStorage persistence
- Delete confirmation modal
- Light/dark mode
- Yup form validation
- React.memo optimization

## Technologies

- React.js
- Vite
- React Hooks
- Yup
- CSS
- localStorage
